# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | Yes       |

## Reporting

Report suspected vulnerabilities to `security@nyxk.com.br`. Do not open a public issue for security reports.

## SLA

Security reports are acknowledged within 72 hours. Fix targets are prioritized by severity, exploitability, tenant-isolation impact, payroll/regulatory impact, and available mitigations.
