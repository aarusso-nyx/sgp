# Prompts Executáveis de Decisão

Este diretório contém prompts para decisões de owner antes de reabrir escopos postergados do SGP v0.0.1.

`docs/audit/plan/` permanece histórico. Novos prompts operacionais devem ficar aqui quando não forem evidência gerada.

## Escopo ativo

- Não implementar escopo postergado a partir destes prompts sem resposta explícita do owner.
- Arrecadação Previdenciária permanece rastreada apenas em `docs/audit/plan/future-arrecadacao.prompt.md` até ser reaberta.
