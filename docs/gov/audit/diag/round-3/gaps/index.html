4. Newly-surfaced items in round-3​

These were not present in round-2's gap register; they emerged from the round-3 governance/tooling consolidation:

  1. FR-ledger parser misfire. scripts/lib/audit/fr-ledger.mjs reads docs/gov/evidence/implementation-status.md for "current scope" bullets but the consolidated narrative now contains zero parseable bullets, so the FR ledger has only FR-001 (a stub). See docs/gov/audit/functional-requisites.md:4-6. Action: either restore bulletized current-scope items in the implementation-status doc, or rewrite the parser to walk the docs/eng/domains/ headings.
  2. Empty FE feature directories. Three directories under frontend/src/app/features/ (convenio, relatorio, shared-platform) have 0 *.ts files (see docs/gov/audit/inv/round-3/backend.md and docs/gov/audit/inv/round-3/frontend.md). Either dead placeholders (cleanup) or unimplemented (track in a backlog item). R3-020 closed modules; this is the next sweep.
  3. Backlog ledger refresh blocked. npm run audit:backlog requires docs/work/round-3/closure.json (a wave-execution artefact). For an audit-only round there is no closure.json; the persistent docs/gov/audit/backlog-ledger.md therefore reflects round-2 closure, not round-3. This is by design (the README at docs/gov/audit/README.md:36 documents the choice), but worth flagging.
  4. docs/refs/ size drift. Round-3 added ~150 k LOC of cached primary regulatory text. These files are big enough to dominate hotspots (hotspots.md top rows). Recommend adding them to a future hotspots-exclude list so genuine source hotspots stay visible.
  5. Two unstaged docs/user/ files at audit start. M docs/user/README.md, ?? docs/user/scripts.md. Pre-existing, not produced by audit; left untouched per round-3 read-only constraint.

5. Top-5 risks (forward-looking)​

  1. PAdES go-live gate — items 1 and 2 in §1 + §2 above. Without R3-052 landing, S-1.3 signatures will be rejected by SEFAZ validators.
  2. DCTFWeb / EFD-Reinf compliance gap (items 2, 4 in §1). Audit findings + potential FIR fines.
  3. PII encryption coverage — 19 high/medium PII columns still in plaintext per live-data-inventory.md. LGPD breach-containment incomplete.
  4. Worker scheduling primitives — raw setInterval is brittle under restart / multi-instance deploy; R3-050 still planned.
  5. employees.service.ts 1 763 LOC — central RH bottleneck; refactor still untouched after two rounds.

6. Top-5 quick wins (forward-looking)​

  1. Lei 14.509 golden fixture (S effort) — unblocks compliance check #3.
  2. Empty FE feature directories cleanup (S effort) — finishes R3-020 sweep.
  3. FR-ledger parser fix (S effort) — restores per-FR test coverage mapping.
  4. Hotspots exclude-list for docs/refs/** (XS effort) — restores diagnostic signal.
  5. R3-053 long-tail decision ledger materialization (S effort, governance only).
