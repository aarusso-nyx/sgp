Regulatory Adherence (Round 3)

Round-3 was the round that introduced docs/refs/: a cached set of primary regulatory sources for offline path:line citation. Per docs/work/round-3/00-snapshot.md §"Notable structural additions vs round-2", docs/refs/{esocial,legal,lgpd,tce}/** were populated this round; primary sources should now be cited from there rather than via WebFetch.

The deep round-2 18-cluster regulatory adherence map at docs/work/round-2/06a-regulatory-adherence.md (544 lines) is canonical; this file overlays the round-3 closures and re-anchors the obligations to docs/refs/.

Per-domain scoring​

Scoring legend: DONE = obligation satisfied with evidence and gate; PARTIAL = primary surface exists, breadth or homologation incomplete; PLANNED = backlog item, not landed; ABSENT = no surface or evidence.

Round-3 closure rate​

  • Closed in round-3: LGPD DPO/DSAR (R3-030), LGPD public-power (R3-031), TCE/transparency/comprovante goldens (R3-016, partial — TCE state-specific still planned).
  • Promoted to PLANNED for round-4: eSocial S-5002/S-5012 (R3-042), DCTFWeb CSLL/MIT (R3-040), EFD-Reinf R-2055 (R3-041), SIAFIC e2e (R3-043), TCE RREO/RGF (R3-044), PAdES PKCS#7 (R3-052).

The introduction of docs/refs/** lets future audits cite primary law path:line instead of external URLs. Recommended for round-4: add a docs/refs/<domain>/<obligation>.md cross-reference table to the round-2 18-cluster map so each obligation links to both the law and the implementation.
