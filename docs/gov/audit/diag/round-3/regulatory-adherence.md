# Regulatory Adherence (Round 3)

Round-3 was the round that **introduced [`docs/refs/`](../../../../refs/)**: a cached set of primary regulatory sources for offline `path:line` citation. Per [`docs/work/round-3/00-snapshot.md`](../../../../work/round-3/00-snapshot.md) §"Notable structural additions vs round-2", `docs/refs/{esocial,legal,lgpd,tce}/**` were populated this round; primary sources should now be cited from there rather than via WebFetch.

The deep round-2 18-cluster regulatory adherence map at [`docs/work/round-2/06a-regulatory-adherence.md`](../../../../work/round-2/06a-regulatory-adherence.md) (544 lines) is canonical; this file overlays the round-3 closures and re-anchors the obligations to `docs/refs/`.

## Per-domain scoring

Scoring legend: **DONE** = obligation satisfied with evidence and gate; **PARTIAL** = primary surface exists, breadth or homologation incomplete; **PLANNED** = backlog item, not landed; **ABSENT** = no surface or evidence.
