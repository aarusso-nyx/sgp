Hardening Evidence​

P.09 is closed because every runtime uses createLoggingModule(...) and the runtime logger is driven by docs/gov/privacy/redactions.json. The focused logging specs prove redaction for CPF/CNPJ, PIS/PASEP, email, bank account fields, authorization headers, and nested PII.

R.07 is closed within ADR-021's accepted boundary. SGP supports software A1/PKCS#12 signing and verification; HSM/A3 remains outside SGP scope. The certificate status surface returns only alias, subject, validity dates, days until expiry, and expired/near-expiry flags. It does not return PKCS#12 bytes, passwords, private keys, or certificate PEM values.
