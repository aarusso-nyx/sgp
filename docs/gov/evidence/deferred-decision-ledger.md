- When a deferred area is reopened, update this ledger first, then update the
  owning `docs/eng` spec, route/database/API gates, and tests in the same wave.
- When implementation lands without external homologation, keep the distinction
  between internal runtime coverage and accepted external transmission explicit.
- Do not use `docs/leg` or `docs/work` to override this ledger.
