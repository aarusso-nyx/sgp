# Legacy Documentation Archive

`docs/leg/` is non-authoritative. It preserves legacy and historical material
for traceability, audit, and migration analysis.

## Contents

- `rev-eng/`: reverse-engineered legacy runtime evidence.
- `sql-reference/`: SQL Server legacy schema and seed reference inventory.
- `audit/`: historical audit plans and retired diagnostics/inventory routing.
- `handoff/`: historical agent or operator handoff notes.
- `old-specs/`: old, external, or pre-v0.0.1 specs that are not current SGP
  acceptance criteria.

Material here must not override `docs/eng/`. Promote any current decision into
`docs/eng/` before using it as implementation authority.
