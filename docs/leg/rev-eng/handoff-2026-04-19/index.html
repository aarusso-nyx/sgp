SGP Handoff (2026-04-19)

This handoff captures implementation state for backend/database work completed in this session, with enough detail for another agent to resume safely.

Scope Completed​

  • Backend document workflow implemented with S3 pre-signed URLs and PostgreSQL persistence.
  • Permission model aligned and tightened for documents.
  • Route alignment completed (register via path parameter).
  • Error semantics aligned for upload registration.
  • RLS policy alignment completed for document permissions.
  • Seed/bootstrap and governance artifacts updated.
  • Build, unit tests, and e2e tests passing.

Implemented API Behavior​

Documents​

  • POST /documents/presign-upload

    • Requires: documents:upload
    • Creates upload session + returns presigned upload URL.

  • POST /documents/uploads/:id/register

    • Requires: documents:register
    • Validates upload session state + S3 object existence.
    • Registers/updates document_attachment.
    • Marks upload session REGISTERED.

  • GET /documents/:id/presign-download

    • Requires: documents:download
    • Returns short-lived presigned download URL.
    • Writes document_download_audit.

  • GET /documents

    • Requires: documents:download

  • GET /documents/:id/download-audit

    • Requires: auditoria:read

IAM​

  • GET /iam/permissions
    • Requires: iam:read.

Permission Changes​

Added runtime permissions:

  • documents:upload
  • documents:register
  • documents:download

Updated group mappings:

  • SGP_RELATORIO and RELATORIO now include all three documents:* permissions.
  • SGP_ADMIN / ADMIN include them via full permission set.

Error Semantics (Register)​

  • Missing upload session: 404.
  • Invalid/expired session state: 409.
  • Missing S3 object at expected key: 404.
  • S3 infrastructure/validation failure: 503.

Database / RLS Alignment​

RLS policy updates in source/database/sql/12-rls-policies.sql:

  • document_upload_session:
    • insert => documents:upload
    • update => documents:register
    • select => documents:upload or documents:register
  • document_attachment:
    • select => documents:download or auditoria:read
    • write => documents:register
  • document_download_audit:
    • insert/select => documents:download (plus audit readers for select)

Seed / Config​

  • Seed transaction now sets:
    • set_config('app.bypass_rls', 'true', true)
  • Environment validation now includes S3-related config:
    • S3_REGION
    • S3_DOCUMENTS_BUCKET
    • S3_DOCUMENTS_PRESIGN_EXPIRES_SECONDS
    • S3_DOCUMENTS_DOWNLOAD_EXPIRES_SECONDS
    • S3_DOCUMENTS_KEY_PREFIX
