# Legacy Reverse Evidence Archive

This directory stores reverse-engineered artifacts produced from legacy runtime inspection.

Status: non-authoritative evidence archive.

Use these files for traceability and audit only. They must not override `docs/eng/`.

Coverage/deprecation tracking lives in `deprecation-status.md`.

`legacy-assumptions.md` records observed, inferred, and unverified decisions
carried from legacy evidence into the modern schema. It remains evidence for
traceability, not an authority over `docs/eng/`.
